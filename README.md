An entry for the [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty on make.fun: one original funny line — a safety warning label that should be printed on every human — under 160 characters.

## The line

> WARNING: Operates on coffee, spite, and 4 hours of sleep. Says 'I'm fine' while visibly on fire. Do not shake.

Written as a real product warning label: the fuel (coffee, spite, too little sleep), the classic denial ("I'm fine"), and a handling instruction — all things anyone recognizes in themselves or the people around them.

## How to run

```sh
python3 main.py
```

`main.py` (stdlib only) validates the line is 1–160 characters and a single line, then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
